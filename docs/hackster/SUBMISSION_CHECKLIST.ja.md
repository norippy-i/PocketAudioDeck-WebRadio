## 公開前に必要

- [ ] 完成品のカバー写真（横位置推奨）
- [ ] PCB表面・裏面の写真
- [ ] 分解または組み立て途中の写真
- [ ] ラジオ画面とスペクトラムが見える写真
- [ ] MP3画面が見える写真
- [ ] 45〜90秒程度の動作動画（強く推奨）
- [ ] Hackster.ioへサインイン
- [ ] Hacksterプロジェクトを2026年中に初公開
- [ ] 公開後のHacksterプロジェクトURLを控える
- [ ] M5Stack公式GoogleフォームへHackster URLを送信

## 動画の推奨構成

1. 完成品の外観
2. 電源投入とウェルカム画面
3. Web Radioの接続、曲名、スペクトラム
4. SW1/SW2による局切り替え
5. 音量変更とミュート
6. KEY2長押しによるMP3モード切り替え
7. MP3の曲名、アーティスト、進捗、再生/停止
8. SDカードの挿入または取り外し検出
9. PCB、回路図、GitHubリポジトリを短く表示
